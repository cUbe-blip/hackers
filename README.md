- [scss](https://sass-lang.com/)
- [pnpm](https://pnpm.io/ja/)

![screenshot of `App.tsx`](src/assets/png/preview.png)

## Setup

- Run `pnpm install` (or `npm install`).
- `pnpm dev` (or `npm dev`) для дебага (port: 8081).
- `pnpm build` (or `npm build`) для продакшен сборки.
- `pnpm serve` (or `npm serve`) для пердварительного просмотра (port: 8080).
